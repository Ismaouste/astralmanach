# Code of conduct

Be kind and be precise. Critique code, data and ideas, not people. Harassment, insults and personal attacks have no place in issues, pull requests or discussions.

Maintainers may edit, close or remove contributions that break this, and may block repeat offenders. To report a problem, use GitHub's private vulnerability reporting form or the contact on the maintainer's profile.

This is a short adaptation of the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 2.1.
